# ЖАВА — готовый Java-проект, этап 1 (SQL Server Express)

Сделано под **текущий проект пользователя**: Java 21, Spring Boot 4.1.2, пакет `kg.java.javaplatform`, SQL Server `SQLEXPRESS`, база `java_platform`, логин `java_user`.

## Самый простой вариант: открыть ZIP как новый проект

1. Закрой старый проект в IntelliJ IDEA, **не удаляй его**.
2. Распакуй ZIP в отдельную папку, например `C:\Users\NoutSpace\IdeaProjects\JAVA_READY`.
3. В IntelliJ IDEA: **File → Open →** выбери папку распакованного проекта **ЖАВА_готовый_проект_SQL_Server** (папку, где находится `pom.xml`). Подтверди импорт Maven.
4. SQL Server Management Studio: подключись к `Sabina\SQLEXPRESS` **через Windows Authentication**, открой **New Query**, скопируй содержимое `setup_database.sql`, выполни F5. Таблица `app_users` будет создана в базе `java_platform`, если её ещё нет.
5. В IntelliJ: **Run → Edit Configurations**. Запусти `JavaApplication`; в **Environment variables** добавь `DB_PASSWORD` и значение пароля **SQL Server-пользователя** `java_user` (тот же, что работал в SSMS). Пароль **никому не отправляй**.
6. Запусти `JavaApplication`, открой `http://localhost:8080`.
7. Нажми **Создать аккаунт**, выбери категорию, зарегистрируйся, войди через email и пароль нового аккаунта. **Этот пароль не равен паролю SQL Server**.

## Уже работает

- Главная адаптивная страница с разделами: стажировки, практика, волонтёрство, помощь.
- Регистрация 5 типов пользователей в таблицу `app_users` SQL Server.
- Безопасное хеширование паролей BCrypt, вход по email и паролю, выход.
- Личный кабинет, перенаправление по роли и разграничение доступа по ролям.

## Ещё НЕ реализовано

- Публикации стажировок и практики, лента, сообщения, лайки, свайпы, отклики, уведомления, Google/Apple. Это следующие этапы. Не вводите реальные личные данные до полноценного развертывания и проверки безопасности.

## Если при запуске ошибка

- `Login failed for user java_user` — проверь переменную `DB_PASSWORD` (это пароль к SQL Server, не пароль регистрации на сайте).
- `SQL Server Browser` / `TCP/IP` — убедись, что включён TCP/IP для SQLEXPRESS, запущен SQL Server Browser, после изменения протоколов перезапущен SQLEXPRESS.
- `Invalid object name app_users` — запусти `setup_database.sql` от Windows-администратора SSMS в правильной базе.
- `Access denied`, `user does not have permission` — проверь, что права из конца скрипта SQL выданы.
- Если браузер открыл старую страницу Spring Security — убедись, что запущен **новый**, а не старый проект, и нет двух программ на порту 8080.

> Этот ZIP — полноценный отдельный Maven-проект. **Не копируй всё поверх старого проекта целиком**: лучше открой этот архив как новый, чтобы случайно не получить два класса `JavaApplication` и конфликтующие настройки.
